# ReactJsonView Props Reference

Complete reference of all configurable properties accepted by `<ReactJson />` (`ReactJsonView`).

| Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `src` | `object \| Promise<object>` | *Required* | Input JSON object or a `Promise` resolving to JSON (supported natively via React 19 `use()` & `<Suspense>`). |
| `name` | `string \| false \| null` | `"root"` | Name of the root node. Pass `null` or `false` to omit the root name. |
| `theme` | `ThemeKeys \| ThemeObject` | `"rjv-default"` | Theme name or a custom Base16 theme object. Supported built-in themes include `rjv-default`, `monokai`, `ocean`, `solarized`, `tomorrow`, `eighties`, `rjv-grey`. |
| `style` | `React.CSSProperties` | `{}` | Inline CSS styling applied to the outer container. Overrides theme defaults. |
| `iconStyle` | `'circle' \| 'triangle' \| 'square'` | `"triangle"` | Style of node expand/collapse icons. |
| `indentWidth` | `number` | `4` | Indentation width (in characters) for nested objects and arrays. |
| `collapsed` | `boolean \| number` | `false` | When `true`, collapses all nodes by default. If a number is provided, collapses all nodes deeper than the specified depth. |
| `collapseStringsAfterLength` | `number \| false` | `false` | Truncates strings longer than the specified length with an ellipsis. Clicking the value toggles full visibility. |
| `shouldCollapse` | `(field: CollapsedFieldProps) => boolean` | `false` | Callback determining whether an object or array should collapse by default based on node metadata. |
| `groupArraysAfterLength` | `number` | `100` | Displays long arrays in paginated subgroup brackets of the specified size. |
| `enableClipboard` | `boolean \| ((copy: OnCopyProps) => void)` | `true` | Allows copying values to clipboard by clicking the clipboard icon. Also accepts a custom copy callback. |
| `displayObjectSize` | `boolean` | `true` | Displays the key count or item count next to objects and arrays. |
| `displayDataTypes` | `boolean` | `true` | Displays type indicator labels (e.g., `string`, `int`, `float`) before values. |
| `quotesOnKeys` | `boolean` | `true` | When `false`, removes surrounding quotes from object keys (`name:` instead of `"name":`). |
| `onEdit` | `(edit: InteractionProps) => false \| unknown` | `false` | Enables inline value editing. Returning `false` aborts the change. |
| `onAdd` | `(add: InteractionProps) => false \| unknown` | `false` | Enables adding new key-value pairs to objects and arrays. Returning `false` aborts the change. |
| `onDelete` | `(del: InteractionProps) => false \| unknown` | `false` | Enables removing keys and elements. Returning `false` aborts the deletion. |
| `onSelect` | `(select: OnSelectProps) => void` | `false` | Invoked when clicking on a value in the tree. |
| `sortKeys` | `boolean` | `false` | Sorts object keys alphabetically. |
| `defaultValue` | `string \| number \| boolean \| array \| object \| null` | `null` | Default value prefilled when adding a new key. |
| `validationMessage` | `string` | `"Validation Error"` | Custom message displayed when `onEdit`, `onAdd`, or `onDelete` returns `false`. |
| `displayArrayKey` | `boolean` | `true` | Prefixes array items with their zero-based index. |

---

## Interaction Handlers (`onEdit`, `onAdd`, `onDelete`)

When `onEdit`, `onAdd`, or `onDelete` callbacks are provided, edit controls become accessible. The handler receives an interaction event object with the following shape:

```typescript
interface InteractionProps {
  /** Updated copy of the entire JSON root after modification */
  updated_src: object;
  /** Property key or array index being modified */
  name: string | null;
  /** Hierarchical path array to the target variable */
  namespace: (string | number | null)[];
  /** New value entered by user (for edit and add operations) */
  new_value?: unknown;
  /** Existing value before the modification */
  existing_value?: unknown;
}
```

Returning `false` from any interaction callback prevents the state change from taking effect.
