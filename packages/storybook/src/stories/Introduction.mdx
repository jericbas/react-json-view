### 📖 About `react-json-view`

`react-json-view` is an interactive React component for displaying, inspecting, and editing JavaScript objects and JSON trees in web applications.

### ✨ Modernization Highlights

- ⚛️ **React 19 & Suspense First:** Direct unwrapping of async `Promise<object>` with React's `use()` hook.
- 📘 **Type-Safe:** Built with TypeScript strict mode with fully exported types (`ReactJsonViewProps`, `ThemeKeys`, interaction event types).
- 📦 **Modern Bundling & Workspaces:** NPM workspaces separating `@react-json-view/core` from `@react-json-view/storybook`.
- 🎨 **Base-16 Theming:** Seamless support for built-in and custom base-16 themes, custom SVG icons, and interactive editing callbacks (`onEdit`, `onAdd`, `onDelete`).
